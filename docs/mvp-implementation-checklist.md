# Isekai Slime Summoner 단계별 구현 체크리스트

## Roulette summon vertical slice

- [x] Contract is consumed once when a summon starts.
- [x] Result is resolved before reel animation and committed after animation or skip.
- [x] Currency consolation result grants gold.
- [x] Direct-rank-one jackpot result prefers unowned rare units when configured.
- [x] Summoned units are registered in the 12-slot bench prototype.
- [x] DOTween reel movement, final-card emphasis, and skip button are wired.
- [x] Connect bench cards to world drag placement.
- [x] Connect duplicate bench cards to in-game merge.

> 날짜·주차가 아닌 **의존성 순서**로 진행한다. 각 항목은 구현과 테스트가 모두 끝났을 때 체크한다.

관련 기준 문서: [SPEC.md](SPEC.md), [ui-guidelines.md](ui-guidelines.md), [mvp-functional-plan.md](mvp-functional-plan.md)

## 사용 규칙

- `[ ] 구현`: 코드·에셋·데이터 작업이 끝나면 체크
- `[ ] 테스트`: 해당 기능의 테스트 케이스가 통과하면 체크
- `[ ] 증거`: 로그·스크린샷·실기기 결과를 남기면 체크
- 기능을 줄이는 대신, 먼저 공통 시스템을 만들고 기획서의 콘텐츠를 데이터로 채운다.
- 웨이브 수·몬스터 구성·이벤트 발생은 `StageTimeline`으로 제어한다.
- 완료한 기능은 다른 기능을 깨뜨리지 않았는지 전체 런 회귀 테스트를 한다.
