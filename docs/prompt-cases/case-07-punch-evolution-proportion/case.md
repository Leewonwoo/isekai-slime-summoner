# 사례 7: ★2 주먹 슬라임의 과도한 주먹 비율 축소

- 날짜: 2026-07-19
- 도구: ChatGPT image_gen
- 목표: ★1의 둥근 젤리 몸체 정체성을 유지하면서 눈·입과 짧은 양팔이 생긴 ★2 주먹 슬라임 제작

## v1 — 실패

- 프롬프트:

```text
Image 1의 ★1 주먹 슬라임 팔레트·몸체·픽셀 스타일을 유지한다.
작은 사각 눈 2개와 단순한 미소를 추가하고, 몸체 좌우에 정확히 두 개의
짧은 젤리 팔과 둥근 주먹을 붙여 공격 준비 자세를 만든다.
다리·근육질 몸통·장비 없이 단일 정면 16-bit 픽셀 스프라이트로 생성한다.
```

- 결과: `v1.png`
- 문제점: 양쪽 주먹이 몸체 높이의 절반에 가까울 정도로 커져 세 덩어리가 나란히 놓인 실루엣이 되었다. ★1 몸체에 팔이 추가된 진화가 아니라 큰 주먹이 주인공처럼 읽혔다.

## v2 — 개선

- 바꾼 것: 수정 대상을 팔과 주먹으로 한정하고, ★1 이미지를 두 번째 몸체 기준으로 다시 제공했다. 양팔은 좌우 하단에 밀착하고 주먹 높이는 몸체의 약 1/4 이하, 전체 폭은 몸체보다 조금만 넓도록 상대 크기와 배치를 명시했다.
- 사용 기법: **identity anchor**, **precise-object-edit**, **invariant locking**, **relative-size constraint**, **negative prompt**
- 프롬프트:

```text
Use case: precise-object-edit
Image 1은 수정할 첫 ★2 시안이고 Image 2는 정확한 ★1 몸체 기준이다.
Image 1의 팔과 주먹만 수정한다. 양팔을 훨씬 짧게, 양쪽 주먹을 훨씬 작게
만들어 ★1 젤리 몸체의 좌우 하단에 밀착한다.
각 주먹은 본체 높이의 약 1/4 이하여야 하며, 전체 캐릭터 폭은 원래 몸체보다
조금만 넓어야 한다. ★1의 둥근 몸체가 주 실루엣이어야 한다.
회청색 팔레트, 1px 외곽선, 크림색 하이라이트, 작은 눈과 미소는 그대로 유지한다.
다리, 근육질 몸통, 큰 주먹, 분리된 주먹, 추가 팔다리, 장비, 이펙트는 금지한다.
```

- 결과: `v2.png`

## 교훈

- 진화형에 팔다리를 추가할 때는 “작게”만 지시하지 말고, 기준 몸체 이미지를 함께 고정한 뒤 팔다리의 상대 크기·부착 위치·허용되는 전체 폭을 수치 관계로 제한한다.
