# 사례 09: 고블린 본체형 사망 시트를 전 종 공용 VFX로 수정

- 날짜: 2026-07-21
- 도구: Codex image_gen
- 목표: 모든 고블린 체형·무기·속성에 재사용할 수 있는 9프레임 사망 소멸 이펙트 제작

## v1 — 실패

- 프롬프트: 일반 고블린 정체성을 유지하며 몸체가 녹갈색 픽셀 조각으로 분해되는 3×3 9프레임 시트
- 결과: `v1.png`
- 문제점: 일반병 본체와 몽둥이가 프레임에 포함되어 마법사·궁수·대형 보스 등 다른 고블린에 적용하면 외형이 순간적으로 일반병으로 바뀐다.

## v2 — 개선

- 바꾼 점: 고블린 이미지를 **팔레트 참조만**으로 한정하고, 캐릭터 중심이 비어 있는 방사형 마력 파열·파편만 생성하도록 대상을 분리했다.
- 사용 기법: **참조 역할 분리(Role-bound reference) + 강제 부정 프롬프트(Explicit negative constraints)**
- 프롬프트: 고블린 본체·얼굴·귀·팔다리·무기·의상·실루엣을 절대 그리지 않고, 올리브·갈색·황금 픽셀 파편이 중심에서 퍼졌다가 9프레임에 걸쳐 사라지는 공용 VFX
- 결과: `v2.png`

## 교훈

- 여러 캐릭터에 공용 적용할 이펙트는 특정 캐릭터의 신체를 애니메이션하지 말고, 캐릭터 렌더러와 독립된 추상 파편·섬광 레이어로 설계한다.
