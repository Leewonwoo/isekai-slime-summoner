# 사례 2: 십자형 전장에서 무경로 폐쇄형 숲 전장으로 전환

- 날짜: 2026-07-13
- 도구: ChatGPT 이미지 생성
- 목표: 이세계에 소환된 학생이 고블린 숲에서 살아남는 디펜스 게임의 인게임 배경 제작
- 연결 에셋: `ingame_stage_2.png`(비채택), `ingame_stage_3.png`(채택)

## v1 — 실패

- 프롬프트: 16-bit 픽셀 아트, 고블린 숲의 네 방향 교차로, 중앙 소환진과 귀환 포탈, 네 개의 고블린 진입로, 토템·울타리·횃불·건물 등 숲 장식, 모바일 타워 디펜스 배경.
- 결과: `v1.png`
- 문제점: 기존 십자형 레인과 슬롯 중심 구조가 강하게 남아 원래의 게임과 차별성이 약했다. 중앙 포탈과 여러 장식 프롭이 플레이 공간을 나누고, 몬스터가 특정 길에서만 등장하는 인상을 줬다.

## v2 — 개선

- 바꾼 것: 기존 시안을 이미지 편집 대상으로 사용하고, 십자형 길·레인·슬롯·소환진·포탈·토템·울타리·횃불·건물·장식 프롭을 전부 제거했다. 숲 바닥을 전체 플레이 공간으로 만들고, 사방의 숲 경계만 남겼다.
- 사용 기법: **image-to-image edit**, **스타일 앵커 보존**, **negative prompt**, **제약 조건 고정(constraint locking)**
- 프롬프트: 기존 맵의 16-bit 픽셀 스타일과 어두운 숲 팔레트는 유지한다. 연속된 자연 숲 바닥과 불규칙한 나무 경계만 남기고, 길·트레일·레인·십자 형태·그리드·배치 타일·룬·포탈·신전·오두막·울타리·문·횃불·배너·토템·버섯·배치된 바위·장식 프롭을 만들지 않는다. 특정 방향의 입구나 중심 초점을 만들지 않으며, 사방에서 몬스터가 등장할 수 있는 중립적인 폐쇄형 숲 전장으로 만든다.
- 결과: `v2.png`

## 교훈

- 게임플레이 구조를 배경 이미지에 직접 그리지 말고, **맵은 중립적인 플레이 공간으로 만들며 스폰·슬롯·유닛·장식은 Unity에서 분리 배치한다.**
