# 소환사 애니메이션 스프라이트 프롬프트

소환사 캐릭터 앵커는 `ArtSource/units/MAIN_SUMMONER.png`이며, 원본 외형은 검은 머리·정장 교복·붉은 넥타이·굽은 나무 지팡이·보라 수정으로 고정한다. 시트 원본은 `ArtSource/units/`, 게임용 가공본은 `Assets/Art/`에 둔다.

> 모든 시트는 [캐릭터 애니메이션 공통 마스터 프롬프트](animation-master-prompt.md)의 `HUMANOID` 프로필을 사용한다. 흔들림이 있는 기존 시트는 정렬 참조 Image 2로 사용하지 않고, 검수 통과한 시트만 승인 기준으로 승격한다.

## 공통 규격

- strict 16-bit pixel art, 기존 소환사와 동일한 얼굴·복장·지팡이·픽셀 크기
- 정면 전신, 모든 프레임에서 동일한 크기와 기준점
- 정확히 3×3, 총 9프레임, 각 셀 128×128px 기준
- 배경은 완전히 평평한 `#00FF00` 크로마키. 바닥·그림자·반사·텍스트·워터마크 금지
- Unity 임포트: Sprite Mode Multiple, 128×128 고정 셀 슬라이스, 동일 Center 피벗, Filter Point, Compression None, PPU 140, Mipmap Off

## Idle 시트 — `MAIN_SUMMONER_idle_sheet.png`

몸 전체가 아주 작게 위아래로 바운스한다. 2~3프레임에서 무릎을 살짝 접고, 좌우 이동·걷기·지팡이 흔들기는 넣지 않는다. 9프레임은 중립 자세로 이어져야 한다.

프레임 순서: 중립 → 하강 시작 → 최저 crouch → 상승 → 중립 → 약한 upward stretch → 하강 정착 → 상승 복귀 → 중립.

## 공격 시트 — `MAIN_SUMMONER_attack_sheet.png`

지팡이를 크게 휘두르지 않고 살짝 위로 들어 올리는 기본 공격이다. 지팡이와 보라 수정은 모든 프레임에 남고, 손은 지팡이에 붙어 있어야 한다.

프레임 순서: 중립 → 준비 무릎 굽힘 → 지팡이 상승 시작 → 가볍게 들어 올림 → 최고점 유지 → 하강 시작 → 거의 원위치 → 몸 정착 → 중립.

### 공통 프롬프트 제약

소환사 외형 변경, 추가 캐릭터, 투사체, 마법 폭발, 큰 이펙트, 모션 블러, 프레임 겹침, 셀 테두리, 라벨, 회색 배경을 금지한다. 애니메이션은 동작만 바꾸고 캐릭터 정체성과 지팡이 실루엣은 고정한다.
